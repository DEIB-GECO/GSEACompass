Information about plots
GSEA and GSEA Preranked
  • Enrichment Plot: Select 1 or more rows. Running enrichment score for the selected gene set.
  • Similarity Graph: Select rows (or none to use all visible). Interactive network graph for semantic similarity between gene set names.
  • Similarity Heatmap: Select rows (or none to use all visible). Heatmap of the semantic similarity between gene set names.
  • Dotplot: Select 1 numeric column (e.g., NES, FDR) AND select rows (or none to use visible). Dotplot across multiple gene set.
  • Heatmap (GSEA only): Select exactly 1 row. Expression heatmap for the lead genes of a specific gene set.
  • Intersection over Union: Select 2 or more rows and no column. Overlap of leading genes between different gene sets.
  • Wordcloud: Select 1 text column (Term or Lead_genes) AND select rows (or none to use visible). Word cloud highlighting most frequent terms.
ssGSEA and GSVA
  • Heatmap: No rows or columns to be selected. Heatmap of NES (for ssGSEA) or ES (for GSVA) across all samples.
